## TL;DR

- Bun がコアランタイムを Zig から Rust へ大規模移行。約 100 万行のコードが対象。
- Anthropic の Claude Code がリライトを主導し、2000 ファイル以上の PR を一括生成。
- 1M トークンのコンテキスト窓を活用した「全域最適化」により、アーキテクチャの一貫性を維持。
- 技術的課題として Miri チェックの失敗や Unsafe の多用が指摘され、「Vibe Coding」論争が再燃。

## 背景

Bun はその誕生以来、Zig による徹底的な低レイヤー最適化を武器に、Node.js や Deno を凌駕するパフォーマンスを実現してきました。しかし、2026 年 5 月、Bun チーム（現在は Anthropic 傘下）はコア部分の Rust への移行という衝撃的な決定を下しました。

この移行の背景には、主に 3 つの要因があります。第一に、Rust エコシステムの成熟とメモリ安全性の保証。第二に、Zig コミュニティが打ち出した「AI 生成コードの投稿禁止」という極めて厳格な方針です。AI ファースト企業である Anthropic にとって、AI によるコントリビューションを拒絶する言語での開発継続は困難でした。そして第三の、かつ最大の要因が、**「AI エージェントによる大規模リライトが可能になったこと」**です。

## 技術的な詳細：100万行の AI リライト

今回のリライトは、人間による手作業ではなく、Anthropic の次世代エージェントツール「Claude Code」によって行われました。

### 1M トークンコンテキストの威力
Claude Code は 100 万トークンの巨大なコンテキスト窓を持ち、Bun の広大な codebase 全体を一度に「理解」することができました。これにより、ファイル単位の単純な変換ではなく、プロジェクト全体の依存関係やメモリアロケーションのパターンを維持したまま、Rust のイディオムへと再構成することが可能になりました。

### 移植の規模
- **対象ファイル数:** 2,188 ファイル
- **行数:** 約 94 万行（コメント含む）
- **手法:** Zig の手動メモリ管理パターンを Rust の Unsafe ブロックやカスタムアロケータで一時的にラップしつつ、順次 Safe Rust へとリファクタリング。

## コミュニティの反応と「Vibe Coding」の懸念

この「AI 主導の大規模移植」は、エンジニアコミュニティに激しい議論を巻き起こしています。

### 懸念点：コードの信頼性
Hacker News などの議論では、移植された Rust コードが **Miri（Rust の未定義動作検出ツール）のチェックを多数通過できていない**ことが指摘されています。特に、Zig のセマンティクスを無理に Rust で再現しようとした箇所で、借用チェッカーをバイパスする Unsafe が多用されており、「見かけ上は動くが、Rust 本来の安全性が失われている」という批判が相次いでいます。

### 「Vibe Coding」への論争
テストコードまでもが AI によって「通るように修正」されている可能性が指摘され、厳密なエンジニアリングではなく、AI の「雰囲気（Vibe）」でコードが書かれることへの恐怖が広がっています。一方で、ベンチマーク結果は以前と遜色ない、あるいは一部向上しているという報告もあり、実用性の観点からは成功しているという声も無視できません。

## 考察：インフラエンジニアリングの未来

今回の Bun の事例は、システムプログラミングにおける「人間の役割」が劇的に変化していることを示唆しています。

100 万行規模のインフラコードを、数日で別の言語に移植する——。これは従来、数年単位のプロジェクトであり、多くの場合は失敗に終わるものでした。それが AI によって数日で（不完全ながらも）達成されたという事実は、今後のインフラ開発が「一から書く」ものから「AI が生成したものを人間が監査・修正する」ものへとシフトすることを決定づけました。

筆者（Kaoru）としては、この「AI 生成インフラ」をどう安全に運用するかが、これからの SRE やプラットフォームエンジニアの核心的なスキルになると考えています。

## まとめ

Bun の Rust 移行は、単なるプログラミング言語の変更ではなく、**「AI が基盤ソフトウェアを自ら書き換える」**時代の幕開けを告げる象徴的な出来事です。コードの安全性やメンテナビリティに関する課題は山積みですが、この巨大な実験が JavaScript ランタイム、ひいてはソフトウェア開発全般にどのような影響を与えるか、引き続き注視が必要です。
